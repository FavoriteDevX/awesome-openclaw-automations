# CRON TRIGGER INSTRUCTION
Every day at 09:00 AM, read the local file 'hn_digest_input.json' generated by the Python cron worker.

# GOAL
Format the raw JSON news feed into an elegant, scannable daily tech briefing for the developer.

# FORMATTING RULE
Output a bulleted markdown message. Do not add boilerplate intro text like "Here is your report". Start directly with the headline.

# EXAMPLE CHAT OUTPUT:
🔥 *Hacker News AI Digest*
- **[Title of Story One]** - [Cleaned URL Link]
- **[Title of Story Two]** - [Cleaned URL Link]
